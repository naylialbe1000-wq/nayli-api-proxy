# Nayli API Proxy

Proxy seguro para API key de Anthropic.
Protege la key de todas las apps de PremiumPlus.

## Apps protegidas
- Creatorai Pro
- App de Importaciones Khrisstal
- Nayli Moda
- Elisela Lambert

## Setup
1. Conectar este repo a Netlify
2. Agregar variable de entorno: ANTHROPIC_API_KEY
3. Deploy
